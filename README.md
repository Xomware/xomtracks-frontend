# xomtracks-frontend

Angular frontend for **Xomtracks** — authed browse UI for the cross-conversation
music-share flow (filter by direction / time window), on-the-spot Spotify
playlist creation.

Deploys to `xomtracks.xomware.com`. See `docs/features/xomtracks/PLAN.md` in
the local working tree for the full spec.

## Setup

```bash
npm install
npm start
```
